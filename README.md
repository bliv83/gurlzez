# 🐱 Gurlzez - A Cat's Interactive Journey

Welcome to Gurlzez's digital home! This is an interactive website celebrating the life, moods, and adventures of our beloved cat Gurlzez.

## ✨ Features

- **Interactive Story Gallery** - Explore Gurlzez's life through 4 main chapters:
  - Life in Utrecht - Nostalgic memories of wonderful Dutch years
  - Adventures & Curiosity - Playful explorations and discoveries
  - Her Love for Kelly - Sweet moments with her favorite person
  - The Big Move to Johannesburg - Exciting new African adventures

- **Image Gallery** - Navigate through beautiful photos of Gurlzez
- **Mood Display** - See how Gurlzez is feeling in each chapter
- **Interactive Elements** - Click to show Gurlzez some love with floating hearts
- **Responsive Design** - Beautiful on all devices

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the website.

### Build for Production

```bash
npm run build
npm start
```

## 💜 About Gurlzez

Gurlzez is a curious, adventurous cat who spent wonderful years in Utrecht before embarking on an exciting new chapter in Johannesburg. Her favorite person is Kelly, and she lives every day to the fullest.

## 🚀 Deployment

This project is ready to deploy on Vercel or any Node.js hosting platform.

### Deploy on Vercel (Recommended)

1. Push to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically build and deploy

```bash
npm run build
```
